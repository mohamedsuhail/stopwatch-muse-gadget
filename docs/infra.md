# Build and test infrastructure: what to improve

Written 2026-10-22, after a day with several Claude sessions building, flashing and measuring the
StopWatch from one checkout. Each item says what went wrong, the fix, and roughly how big it is.
Ranked by how much time it would have saved today.

## 1. Get the SDK and build folder out of iCloud

**What happened.** The repo lives in `~/Documents`, which iCloud syncs. iCloud offloaded SDK files
mid-build, so the build had to wait for them to download again, and it left conflict copies
(`.sdk/muse-gadget-sdk/esp32/dependencies 2.lock`, `dependencies 3.lock`). Builds were slow and
some failed.

**Fix.** Default `SDK_DIR` in `scripts/build.sh` and `scripts/flash.sh` to a folder iCloud doesn't
touch, such as `~/Library/Caches/stopwatch-muse-gadget/muse-gadget-sdk`, and keep
`.sdk/` only as an opt-in. The xAI session already builds in `~/Library/Caches/xai-build`. Delete
the `dependencies N.lock` copies. Small.

**Done.** `SDK_DIR` defaults to `~/Library/Caches/stopwatch-muse-gadget/muse-gadget-sdk`
(`scripts/lib/common.sh`); `SDK_DIR=$PWD/.sdk/muse-gadget-sdk` still works. The conflict copies are
deleted.

## 2. One build at a time

**What happened.** Two sessions started `board.sh build stopwatch` on the shared build folder nine
seconds apart. `board.sh` deletes `managed_components/` and `dependencies.lock` at the start and
end of every build, so both failed.

**Fix.** Take a lock in `scripts/build.sh` and `scripts/flash.sh` (`mkdir`-based, since macOS has
no `flock`): print who holds it, and wait or fail. Small.

**Done.** `take_sdk_lock` in `scripts/lib/common.sh`, used by `build.sh`, `flash.sh` and
`save-patch.sh`: `muse-gadget-sdk.lock` next to the checkout, with the holder's script, process and
start time. It fails at once by default, waits with `LOCK_WAIT=<seconds>`, and takes over a lock
whose process is gone.

## 3. A script that saves the SDK patch

**What happened.** `patches/0001` is regenerated by hand: `git add -N` a list of new files, `git
diff`, `git reset`. The list grew (Gemini, xAI, font, partition table) and had to be kept in step in
the README and by every session. A missed file silently drops from the patch.

**Fix.** `scripts/save-patch.sh`: mark every untracked file under `esp32/components/muse` and
`esp32/partitions_stopwatch.csv` (skipping `tape/` and lock files), write the diff, reset, then
check the patch applies to a clean checkout of the pinned commit, and scan it for keys
(`docs/token.md`). Small.

**Done.** `scripts/save-patch.sh`. It writes the patch only if it applies and has no keys, and
says "unchanged" when the diff matches the committed patch. The README's "Changing the SDK patch"
uses it.

## 4. A measurement script

**What happened.** Every flash was followed by the same hand-written capture: open the port, read
for 10–30 s, grep `muse_anim` timing and the heartbeat's `min=`. Opening the port resets the
watch (even with DTR and RTS low), which together with the old every-boot token refresh cost the
pairing five times.

**Fix.** `scripts/measure.sh [seconds]`: capture without extra resets, then print one summary:
decode and tick timing, the internal-RAM low point, any `E (` lines, and whether the token refresh
and pairing held. Add a `--talk` mode that waits for a voice turn and prints its timing line.
Medium.

## 5. Host tests for the avatar code

**What happened.** The 2x and 3:2 scalers, the redraw box and the clip table were checked with
throwaway C harnesses in a scratch folder, which caught a threading bug before it reached the
watch. They're gone now.

**Fix.** `tests/host/` with those harnesses (stub headers for ESP-IDF, `cc -O2`), run by a
`make test` or `scripts/test.sh`. Add `make_anims.py` checks: the pack fits the `anims` partition,
every frame is baseline JPEG, and loop seams are below a set difference. Small to medium.

## 6. CI

**Fix.** A GitHub Actions workflow on push: the host tests, a key scan of `patches/` and docs, and
a firmware build in the `espressif/idf:v6.0.1` container (clone the pinned SDK, apply the patch,
copy the avatar, `board.sh build stopwatch`). It catches a patch that no longer applies or
compiles before anyone flashes it. Medium.

## 7. Small fixes

The first three are done; recording the flashed build is still open.

- The scripts are committed without the executable bit (`100644`), so `./scripts/flash.sh` fails
  with "permission denied". `git update-index --chmod=+x scripts/*.sh`.
- Pin the avatar tools' Python packages (`avatar/requirements.txt`: Pillow) and note ffmpeg; the
  system Python has no Pillow, so a scratch venv was needed.
- `flash.sh`: also take the factory backup with `--after no-reset`, so a first flash resets once.
- Record the flashed build in a file (git describe of the repo, SDK commit, time), and have the
  measure script print it, so a log always says which firmware it came from.

## Not infrastructure, but found along the way

- The token refresh used to rotate the refresh token on every boot. It now happens once (see
  `docs/plan.md`). If Muse's server ever stops rotating tokens, the extra safety still holds.
- Gemini TTS's free tier allows 100 requests a day. xAI is the default when its key is set.
